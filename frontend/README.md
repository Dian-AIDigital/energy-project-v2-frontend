# 新能源荷储技术实证平台 · 运行台（重设计 v1）

依据全局 skill `distinctive-ai-design` 的「探索 → 定义 → 交付」流程重做的前端页面。技术栈：Vue 3 + Vite + TypeScript，附一个 Node(Express) mock API。

## 运行

```powershell
# 1) 页面（Vite dev server）
cd D:\energy\webapp
node node_modules\vite\bin\vite.js --port 5180

# 2) 可选：Node mock API（页面当前使用本地 mock，接口与之一致）
node server\mock-api.mjs     # http://127.0.0.1:5182/api/meta
```

打开 <http://127.0.0.1:5180/>。

- `?sel=5` 预选 5 号母线（D 换流站，告警态）
- `?scenario=fault` 预选「故障恢复」图层
- 例：<http://127.0.0.1:5180/?sel=5&scenario=fault>

## 设计方向：「图纸即舞台」

| 项 | 决定 |
| --- | --- |
| 用户与主任务 | 研究员在评审现场：选拓扑 → 调源荷 → 提交 → 读节点与波形 |
| 核心隐喻 | 中区是一张通电的电气单线图纸，读数以引出标注贴在图上，波形是图纸下沿的记录纸带，右下角保留工程图签 |
| 构图 | 左 288 px 控制台 / 中 图纸（主视觉）/ 右 316 px 节点档案 / 下 226 px 记录带；标题压缩成 40 px 身份条，不再与图纸争夺视觉重心 |
| 色彩 | 墨蓝黑 `#05080D` + 信号蓝 `#5AA9FF` + 冰青 `#9FE8FF`；琥珀 `#F0A35E` 只用于告警与排队 |
| 字体 | 中文 HarmonyOS Sans SC；数字 Bahnschrift（等宽数字，刷新不跳动）；标号 Consolas |

### 相对上一版（7 区卡片大屏）的关键删减

1. **删掉通栏大标题**：平台名收进 40 px 身份条 + 图签，页面上最大的字让给图纸。
2. **删掉右栏四读数**：U/I/P/Q 只在图上引出标注出现一次，右栏只留档案事实（电压等级/母线号/平衡方式）、机组出力与节点索引。
3. **删掉左栏「工况」重复控件**：工况 = 图纸图层的切换，只在图纸上方出现一次。
4. **删掉四角括号、渐变按钮、发光边框、卡片套卡片**：装饰只保留图纸网格、对位角标、图签、比例尺。
5. **删掉彩色折线图**：波形改为四条独立泳道的记录纸带（U/f/P/Q 各自量程），避免"四色叠加"的模板感。

### 第二轮（7 / 10）

评审三条问题 → 已改：

| 问题 | 改法 | 证据 |
| --- | --- | --- |
| 悬浮卡压住母线、没有引出线，读数与元件脱钩 | 卡片上移，加**引出折线 + 锚点圆环**，锚在母线顶上 | `final-main.png` 水电 D 厂标注 |
| 告警只在文字层，3 m 外看不出与典型日的差别 | 故障元件本体改**琥珀描边**（母线/换流站符号/名称）+ 局部光晕；图签上方加横贯告警条；顶栏状态灯同步转琥珀 | `final-warn.png` D 换流站 |
| trace 仅约 300 px、无刻度，RUN LOG 五条等长条稀释主任务 | 记录带加到 **262 px**（泳道 38 px）；每条泳道补 **Y 刻度 + 量程标签**；铺时间/泳道网格；RUN LOG 收成 **3 行** | `final-main.png` 下带 |

## 可用性修正（用户实测反馈后，最重要的一轮）

用户打开 5180 实看后的四条反馈与对应改动：

| 反馈 | 定量证据 | 改动 |
| --- | --- | --- |
| 页面整体太暗 | 整页平均亮度 **13.5 / 255** | 页面底色 `#05080D→#101A26`、纸面 `rgba(20,32,48)→rgba(34,52,74)`、网格与结构线透明度 +40%、线路描边 `.66→.88`；改后平均亮度 **33.9** |
| 字体较小、看不清 | 正文 12px、节点名 11px、边框字 8—10px | 全局基准 12→**13.5px**；节点名 11→**12.5px**、kV 10→11.5、标注数值 13→**14.5**、记录带数值 11→12.5、侧栏与日志 10→11.5 |
| 居民负荷/储能站/工业负荷等标注遮挡拓扑 | 标签基线 `b.y+34`，而负荷符号底边在 `b.y+26`，字形顶部在 `23` 处相交 | 按符号高度区分基线（机组/母线 36，负荷/储能/换流阀 **48**），底排整体上移 22 单位，标签不再与符号、竖线相交 |
| 告警辨识度低 | 原来只有 10px 琥珀文字 + 一个小圆环 | 换流站**本体琥珀描边**+光晕+告警徽标；图纸上方新增**横贯告警条**（编号 A-05 / 元件 / 原因 / 处置建议）；顶栏状态灯转琥珀；3 m 外可辨 |

附带：标题块加宽 344→420px 消除字段截断；下排节点被选中时，引出标注改放**左侧空白**，不再压 525 kV 主母线。

### 第二轮实测反馈（区域与告警）

| 反馈 | 改动 |
| --- | --- |
| 「告警 A-05」字太小、深字在暗底上发虚 | 徽标 11→**13px 加粗**并改为**实心浅琥珀底 + 深字**（对比 ≈ 9:1）；主文案 12.5→**14.5px**；建议文案 13px；条高 6px→9px |

## 配色方案与造型柔化（第三轮实测反馈）

用户反馈「边框与字体太方正、不自然」「配色可以考虑蓝黑以外」。已做两件事：

**1）造型柔化（全主题生效）**

- 圆角：区块 `14px`、图纸/告警/按钮 `10px`、选项/标签 `6px`、chip 与徽标 `999px`；
- 去掉左侧 2px 竖标识条与 `letter-spacing` 过大的全大写标签，改用底色、圆角、柔和投影区隔区块；
- 字体：数字与标号从 Bahnschrift/Consolas 改为 **HarmonyOS Sans SC**，取消大写化，字距回到 0.2px。

**2）四套配色（`?theme=` 切换）**

| theme | 名 | 底色 | 信号色 | 感觉 |
| --- | --- | --- | --- | --- |
| `blue`（默认） | 蓝黑 | `#101A26` | `#6CB6FF` | 原有的图纸冷感 |
| `graphite` | 石墨绿 | `#101614` | `#7FDC AE` | 低饱和护眼，长时间盯屏最舒服 |
| `sepia` | 暖石灰 | `#17130F` | `#E0A86A` | 黄铜仪器感，比蓝黑温和 |
| `paper` | 米白图纸 | `#EAE4D8` | `#2F6F8F` | 最接近真实工程图纸，会议投屏最亮 |

链接：`/?theme=graphite`、`/?theme=sepia`、`/?theme=paper`（可与 `sel`/`scenario` 叠加，如 `/?theme=paper&sel=5&scenario=fault`）。截图见 `shots/theme-*.png`。

## 评审记录（两轮，评审者只看截图）

### 第一轮（6.5 / 10）

- 整体评分 **6.5 / 10**：「方向与克制都在，但图纸还不是舞台，细节可信度会先于审美被挑出来」。
- 采纳并已修：①通栏标题与右栏读数压过图纸 → 标题收进身份条、读数只留图上；②记录带缺属主与量程 → 标题注明「水电 D 厂端电压」，每条泳道补量程；③图签字段错位、完成/排队同灰 → 字段校正，琥珀专供排队与异常，告警同步到图上节点。
- 采纳未完成（下一轮）：游标同时贯穿图纸与记录带；电压等级差异可再强化（当前用线宽 1.8/2.4/3.2 区分）。

## 未验证（截图无法证明）

- 拖动滑杆后的实时联动、提交到队列的真实时延（当前为本地 mock）
- 键盘焦点顺序与 WCAG 对比度是否达标
- 1440 / 2560 / 3840 分辨率下的重排与可读性
- 动效性能（当前仅保留控件过渡与状态色变化，无持续动画）
