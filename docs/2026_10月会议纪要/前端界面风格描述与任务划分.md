> 依据：`2026_10月会议纪要.md`（2026-10-17）+ 参考效果图 `图片和附件/新能源荷储技术实证平台·科技风界面效果展示.png`

> 配套文档：页面级逐元素规格见《[前端界面详细规格说明](./前端界面详细规格说明.md)》（给不看图也能开发的 agent / 成员用）

## 1. 一句话定位

这是一个 **1920×1080 大屏数据可视化驾驶舱（DataV / 可视化大屏风格）**：
深海军蓝底 + 青蓝色（Cyan）霓虹描边 + 发光标题，整体是典型的"能源电力科技风监控大屏"，一个屏幕内完成 **参数配置 → 拓扑仿真 → 波形与状态监控 → 场景与任务管理** 的全流程闭环。

## 2. 整体风格拆解

| 维度 | 描述 |
|------|------|
| 风格关键词 | 科技风、大屏驾驶舱、深色 HUD、霓虹描边、电力系统 SCADA 质感 |
| 底色 | 深海军蓝（近黑），带径向渐变晕影和底部微弱透视网格 |
| 主色 | 淡蓝 / 青色（#00D8FF 系），用于边框、发光、进度、连线、按钮 |
| 辅助色 | 橙色（告警/越限）、绿色（正常/完成）、蓝色（运行中）、紫色（无功曲线）、红色（严重故障，本图未出现但需预留） |
| 质感 | 面板半透明深蓝底 + 1px 青色发光描边 + 四角亮色折角装饰；标题带辉光（glow） |
| 字体 | 标题加粗白字带青色辉光；正文白色/浅蓝灰；数字建议用等宽或 LED 感字体 |
| 密度 | 高信息密度，12 块功能区域同屏，但通过发光分隔保持清晰层级 |
| 装饰 | 页头左右电路板纹理折角、背景六边形/粒子微光、网格地板，均为低透明度，不抢主体 |

## 5. 通用组件风格规范

| 组件 | 规范 |
|------|------|
| 面板 Panel | 圆角 8px；半透明深蓝底；1px 青色描边 + `box-shadow: 0 0 12px rgba(0,216,255,.25)`；四角 L 形亮色折角；标题行 = 图标 + 18px 粗体白字，下带渐隐分隔线 |
| 主按钮 | 青色渐变填充（#0FA8FF→#00D8FF），深色文字或白色文字 + 外发光；圆角 6px；带图标（如 ▶） |
| 下拉框 Select | 深蓝底、1px 青边、右侧青色 chevron；选中文字白色 |
| 滑块 Slider | 4px 高轨道，已填充段青色渐变发光，圆形青色滑钮带光晕；行尾数字输入框（深底青边）+ 单位 |
| 开关 Switch | 胶囊形，开启 = 青绿渐变 + 白色圆钮居右 |
| 表格 | 表头深蓝底 + 浅蓝灰字；行高 ~36px；斑马纹极弱；状态列为彩色圆点/描边胶囊标签 |
| 状态标签 Chip | 胶囊形 1px 描边 + 同色文字：完成=绿、运行中=蓝、排队中=橙、越限=橙、正常=绿点 |
| 进度条 | 高 6px 圆角，深色轨道 + 青色渐变填充，右侧百分比数字 |
| 缩略图卡 | 深蓝底卡片，选中态 = 青色描边加亮 + 文字变青色 |
| 风险等级 | 5 个小圆角方块，按等级点亮，颜色由绿→橙→红 |

## 6. 动效建议（克制，服务于状态感知）

1. 拓扑连线"能量流动"：虚线沿路径流动（stroke-dashoffset 动画），故障/越限线路改橙色并呼吸闪烁。
2. 告警节点：橙色描边呼吸光晕。
3. 波形图：实时滚动追加，尾部渐隐。
4. 面板载入：整体淡入 + 轻微上移，一次性，不循环。
5. 数字滚动：关键数值变化时补间。

## 7. 任务划分建议

> 按会议纪要：整体开发规划 @刘定蔼。前端 4 人，建议先由 1 人搭骨架定规范，其余 3 人按"列"并行认领，互不阻塞。

### 任务包 T0：设计系统 + 页面骨架（@刘定蔼）
- 范围：工程初始化（Vite + Vue3/TS + Pinia + ECharts，或团队现成栈）、24 栅格布局、Header、通用 Panel 组件、主题 Token、大屏等比缩放适配（1920×1080 基准，`transform: scale` 方案）。
- 产出：`components/Panel.vue`、`styles/theme.ts`、`AppLayout.vue`，以及各面板占位空壳。
- 验收：任何成员把自己认领的面板塞进布局即可用；1080p/2K/带鱼屏不破版。

### 任务包 T1：左侧「用户配置参数面板」（@史梓洋）
- 范围：拓扑选择下拉、4 个滑块（光伏/风电/负荷/储能SOC）、故障设置（类型/位置/开关）、工况选择、提交仿真任务按钮。
- 产出：`ConfigPanel.vue` + `configStore`（Pinia），提交动作对接仿真任务接口。
- 接口：提交仿真任务（POST，参数=拓扑ID+四参数+故障配置+工况ID）；拓扑列表、工况列表的 GET。
- 验收：参数变更实时进 store；提交带完整参数与校验；开关/下拉/滑块均可键盘操作。

### 任务包 T2：中央「拓扑图展示视图」（@刘舜天，工作量最大）
- 范围：单线图画布（变电站/换流站/主网/两风电场/光伏/储能/工业与居民负荷/35kV 与 10kV 母线及连线）、节点状态着色（正常绿/越限橙）、连线能量流动动画、"允许全屏展示"、底部 5 张拓扑缩略图选择条（左右翻页箭头）。
- 产出：`TopologyView.vue`（建议 AntV X6 或自绘 SVG）+ `TopologyMiniCard.vue` ×5。
- 接口：拓扑图数据（后端已排期：8 张拓扑图入库 MySQL，4/2/2 分工）、节点实时量测（电压/电流/功率/状态）。
- 验收：8 张拓扑可切换渲染；越限节点与告警线路正确变色；全屏可用；缩略图选中态正确。

### 任务包 T3：右侧「波形图 + 拓扑节点状态信息」（@曾一凡）
- 范围：双 Y 轴四序列波形图（电压/频率/有功/无功，00:00–24:00）、节点状态表（7 行节点 × 5 列）、右侧"换流站节点信息"详情卡与"功率构成(MW)"迷你柱图。
- 产出：`WaveformChart.vue`、`NodeStatusTable.vue`、`NodeDetailCard.vue`。
- 接口：仿真结果时序数据（对小扰动 MATLAB 程序接入，@刘昭妍）；节点量测数据。
- 验收：图例可开关序列；表格行点击 → 详情卡联动；越限行橙色高亮。

### 任务包 T4：底部「场景库视图 + 仿真任务运行表」（@史梓洋 或 @曾一凡 二次认领）
- 范围：6 张场景卡（缩略图/标签/风险等级/状态）+ 任务表（Task_ID/类型/引擎/进度条/状态/创建时间，5 行示例）。
- 产出：`ScenarioLibrary.vue`、`TaskTable.vue`（进度条轮询刷新）。
- 接口：场景列表 GET；任务列表/进度轮询 GET；点击场景 → 回填 T1 参数（联动）。
- 验收：运行中任务进度条自动刷新；场景卡状态（已就绪/待运行/已完成）样式正确。

### 依赖与联调节奏
1. T0 完成 → T1/T2/T3 并行启动，T4 在 T1/T3 空出人力后接手。
2. 后端里程碑（来自会议纪要）：8 张拓扑图入 MySQL（4/2/2）→ T2 联调；小扰动 MATLAB 接入（@刘昭妍）→ T3 联调；Simulink `.slx` 经 Python 脚本控制仿真任务（@居科维 @雷欣瑶）→ T1 提交链路联调。
3. 所有接口先以 mock 数据开发（建议 `vite-plugin-mock` / MSW），联调期只换 baseURL。

## 8. 技术选型建议

| 关注点 | 建议 |
|--------|------|
| 框架 | Vue 3 + TypeScript + Vite + Pinia（团队如更熟 React 可平移，规范不变） |
| 图表 | ECharts 5（波形图、迷你柱图、仪表类） |
| 拓扑图 | AntV X6（电力单线图节点/连线/动画支持好）或 SVG 自绘 |
| 大屏适配 | 设计稿 1920×1080，根容器 `transform: scale()` 等比缩放 |
| 组件库 | Element Plus / Arco 二次主题化即可，重点控件（滑块、开关、Chip）自绘皮肤 |
