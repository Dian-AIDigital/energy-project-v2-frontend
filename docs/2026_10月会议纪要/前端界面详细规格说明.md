# 前端界面详细规格说明（无视觉可开发版）

> 目标读者：**看不到参考图的 agent 或开发者**。本文档把效果图逐区域、逐元素展开为文字规格，读完即可搭建出布局与视觉一致的页面。
> 参考图（对 sighted 开发者）：`docs/2026_10月会议纪要/图片和附件/新能源荷储技术实证平台·科技风界面效果展示.png`
> 风格总结与任务划分见：`docs/2026_10月会议纪要/前端界面风格描述与任务划分.md`
> 设计基准分辨率：**1920×1080**，单屏大屏，无页面滚动（各面板内部可滚动）。

---

## 0. 全局规格

### 0.1 画布与背景
- 页面整体为一块 1920×1080 深色画布，四周留 16px 内边距。
- 背景：深海军蓝径向渐变，中心约 `#071A38`，四角渐暗至 `#020913`；页面底部有微弱透视网格地板（青色线条，透明度 < 8%），空间中散布少量低透明度光点/粒子。这些装饰层不参与交互。

### 0.2 全局色板（CSS 变量，代码中直接引用）
```css
--bg-page:        #030B1C;   /* 页面底 */
--panel-bg:       rgba(8, 28, 58, 0.55);  /* 面板底，半透明深蓝 */
--panel-border:   rgba(0, 180, 255, 0.45);/* 面板描边 */
--accent-cyan:    #00D8FF;   /* 主强调色 */
--accent-blue:    #1E90FF;   /* 次强调色 */
--text-primary:   #E6F7FF;   /* 主文字，近白微蓝 */
--text-secondary: #7FA8C9;   /* 次文字、单位、表头 */
--success:        #00E676;   /* 绿：正常/完成/已就绪 */
--warning:        #FFA940;   /* 橙：越限/排队中/风险高 */
--danger:         #FF5C5C;   /* 红：严重故障（预留） */
--chart-purple:   #9C6BFF;   /* 无功功率曲线 */
--chart-green:    #3DDC97;   /* 频率曲线 */
--chart-orange:   #FF9F40;   /* 有功功率曲线 */
--chart-cyan:     #00D8FF;   /* 电压曲线 */
```

### 0.3 字体
- 中文标题/正文：系统默认无衬线（思源黑体/微软雅黑）。
- 数字与时间：等宽字体（如 DIN Alternate、JetBrains Mono），保证表格数字对齐。
- 层级：页面主标题 34px 粗体；面板标题 18px 粗体；正文/控件 14px；表格 13px；辅助说明 12px。

### 0.4 通用面板组件 `Panel`
页面共有 **9 个面板**，全部复用同一外壳：
- 圆角 8px；底色 `--panel-bg`；1px 描边 `--panel-border`；外发光 `box-shadow: 0 0 12px rgba(0,216,255,.25)`。
- **四角装饰**：每个直角处有 1 个 L 形亮青色折角（长约 14px、粗 2px、圆角端点），是这套 UI 的标志性元素。
- 标题行：左侧 20px 线性图标（青色发光）+ 18px 粗体白色标题文字；标题下方一条从青色渐隐到透明的分隔线（高 2px）。
- 标题行右侧可放操作按钮（仅拓扑面板有）。
- 内边距 16px；面板之间间距 16–20px。

## 2. 面板A：用户配置参数面板（左列整列，~380×648px）

标题："用户配置参数面板"，图标：齿轮。面板内自上而下 4 个分组，组间有渐隐分隔线。

### 2.1 分组「拓扑选择」
- 组标题行：小图标（拓扑节点形状）+ 文字"拓扑选择"，16px 白色粗体。
- 一个下拉框（Select）：当前值"多源互联微电网拓扑"。样式：深蓝底、1px 青色描边、圆角 6px、高 36px、右端青色向下箭头。
- 数据来源：拓扑列表接口（后端 8 张拓扑）。

### 2.2 分组「源荷储参数」
- 组标题行：小图标 + "源荷储参数"。
- 4 行滑块控件，每行结构相同（行高 ~40px，行距 8px）：
  - 行首：16px 图标 + 参数名（白色 14px）。
  - 中部：水平滑块。轨道高 4px、深蓝色；已填充部分为青色渐变并带辉光；圆形滑钮直径 14px、青色、外圈光晕。
  - 行尾：数字输入框（宽 ~56px、高 30px、深底青边、白色数字右对齐）+ 单位"%"（`--text-secondary`）。
- 四行内容与默认值：
  1. 图标太阳｜"光伏出力"｜滑块｜值 **60** %
  2. 图标风机｜"风电出力"｜滑块｜值 **45** %
  3. 图标房屋/负荷｜"负荷"｜滑块｜值 **70** %
  4. 图标电池｜"储能SOC"｜滑块｜值 **50** %
- 滑块取值范围 0–100，步长 1；滑块与数字框双向绑定。

### 2.3 分组「故障设置」
- 组标题行：⚠ 三角警示图标（橙色）+ "故障设置"。
- 三行控件（行高 ~36px）：
  1. 标签"故障类型"（左，白色14px）+ 下拉框（右，宽 ~180px）：当前值"线路故障"；选项需含：线路故障、设备故障、暂态扰动等。
  2. 标签"故障位置" + 下拉框：当前值"10kV母线1"；选项为当前拓扑的母线/线路节点名。
  3. 标签"是否启用" + 胶囊开关：**开启态**（青绿渐变填充，白色圆钮居右，宽 ~44px 高 22px）。
- 交互约束：故障下拉选项依赖当前所选拓扑；"是否启用"关闭时两行下拉置灰禁用。

### 2.4 分组「工况选择」
- 组标题行：文档图标 + "工况选择"。
- 一行：标签"仿真工况" + 下拉框（宽 ~200px）：当前值"典型日场景"；选项来自工况列表接口。

### 2.5 提交按钮
- 面板底部居中：宽 ~280px、高 44px 的主按钮，文本"▶ 提交仿真任务"（播放三角图标 + 白色 16px 文字）。
- 样式：青蓝线性渐变（左 `#0FA8FF` → 右 `#00D8FF`），圆角 6px，外发光；hover 提亮，active 轻微下压。
- 点击动作：校验参数 → POST 提交仿真任务 → 成功后提示并在面板F任务表头部插入新任务行（状态=排队中/运行中）。

## 4. 面板C：波形图（右列上部，~500×305px）

标题："波形图"，图标：正弦波。
- **图例**（标题下一行，居中横排 4 项，每项 = 短色线段 + 文字，13px）：
  - 青色线 电压(kV)｜绿色线 频率(Hz)｜橙色线 有功功率(MW)｜紫色线 无功功率(MVar)

  - 网格线：极低透明度水平线；无背景填充；线宽 2px。
  - 交互（建议）：图例点击开关序列；`tooltip` 十字准星显示各序列数值。

## 8. 交互与数据流总览（给开发/联调）

```
面板A(参数) --POST--> 后端仿真服务 --> 面板F(任务表轮询进度)
面板B(拓扑选择) --GET 拓扑JSON--> 面板B主画布 + 面板D节点表联动

面板E场景卡点击 --> 回填面板A参数

```

## 9. 验收清单（无视觉 agent 自检用）
1. 1920×1080 下 9 个面板齐全、无滚动条破版；缩小到 1280 宽整体等比缩放不重叠。
2. 所有面板具备：半透明深蓝底、青色 1px 发光描边、四角 L 形折角、图标+标题+渐隐分隔线。

5. 面板C 双 Y 轴 4 曲线 + 可开关图例。
6. 面板D 7 行表、越限行橙色高亮、点击行联动右侧详情卡。

8. 面板F 状态胶囊三色（绿完成/蓝运行中/橙排队中）、进度条随轮询增长、新任务置顶。
