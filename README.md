# 新能源荷储技术实证平台（energy-project-v2）

新能源荷储技术实证平台的前端大屏项目。参考科技风效果图实现：1920×1080 数据可视化驾驶舱，深蓝底 + 青色霓虹描边，单屏完成"参数配置 → 拓扑仿真 → 波形/状态监控 → 场景与任务管理"全流程。

## 技术栈

| 项 | 选择 |
|---|---|
| 框架 | Vue 3 + TypeScript + Vite |
| 状态管理 | Pinia |
| 图表 | ECharts（波形图、功率构成柱图） |
| 拓扑图 | 自绘 SVG（单线图 + 能量流动动画） |
| 适配 | 1920×1080 设计基准，`transform: scale` 等比缩放 |

## 快速开始

```bash
cd frontend
npm install
npm run dev
# http://localhost:5173/
```

生产构建：

```bash
npm run build
npm run preview
```

## 功能面板

| 面板 | 说明 |
|---|---|
| 用户配置参数面板 | 拓扑选择、光伏/风电/负荷/储能SOC 四滑块、故障设置、工况选择、提交仿真任务 |
| 拓扑图展示视图 | SVG 单线图（9 类节点、4 条母线、8 条连线），正常线路青色能量流动、越限橙色呼吸，支持全屏与 5 张拓扑缩略图切换 |
| 波形图 | 双 Y 轴 4 序列（电压/频率/有功/无功）24h 曲线 |
| 拓扑节点状态信息 | 7 行节点量测表，越限行高亮，点击行联动右侧详情卡与功率构成柱图 |
| 场景库视图 | 6 张场景卡（标签/风险等级/状态），点击回填左侧参数 |
| 仿真任务运行表 | 任务进度轮询刷新，提交后新任务置顶插入 |

当前数据全部来自 `src/mock/data.ts`（按规格文档示例数据），联调时替换为真实接口即可，Store 中的 action 已按接口动作组织。

## 目录结构

```
frontend/
├── src/
│   ├── components/        # 6 个面板组件 + 通用 GPanel
│   ├── stores/            # Pinia 全局状态
│   ├── mock/              # mock 数据（拓扑/量测/任务/场景/波形）
│   ├── types/             # TypeScript 类型定义
│   ├── App.vue            # 大屏布局与缩放适配
│   └── style.css          # 设计系统（色板/面板/控件/动画）
└── docs/                  # 会议纪要与设计规格文档
```
