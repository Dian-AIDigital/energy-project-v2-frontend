# 新能源荷储技术实证平台（energy-project-v2）

新能源荷储技术实证平台的前端大屏项目。参考科技风效果图实现：1920×1080 数据可视化驾驶舱，深蓝底 + 青色霓虹描边，单屏完成"参数配置 → 拓扑仿真 → 波形/状态监控 → 场景与任务管理"全流程。

## 技术栈

| 项 | 选择 |
|---|---|
| 框架 | Vue 3 + TypeScript + Vite |
| 状态管理 | Pinia |
| 网络请求 | Axios（已打通跨域代理配置） |
| 图表 | ECharts（波形图、功率构成柱图） |
| 拓扑图 | 自绘 SVG（单线图 + 能量流动动画 + 拖拽缩放 + 防重叠算法） |
| 适配 | 1920×1080 设计基准，`transform: scale` 等比缩放 |

## 快速开始

**1. 启动后端（必须先启动，否则拓扑图无真实数据）**
请参考后端仓库的启动说明（FastAPI + MySQL）。确保后端运行在 `http://127.0.0.1:8000`。

**2. 启动前端**
```bash
cd frontend
npm install
npm run dev
# http://localhost:5173/
```
**3. 演示**
演示时，启动后端后，不必启动前端。直接终端运行start-demo.ps1即可

## 功能面板与数据源

| 面板 | 当前数据源 | 说明 |
|---|---|---|
| 用户配置参数面板 | Mock | 拓扑选择、光伏/风电/负荷/储能SOC 四滑块、故障设置、工况选择、提交仿真任务 |
| 拓扑图展示视图 | **已接入后端 (MySQL)** | 对接 `/api/v1/topologies` 接口，获取真实拓扑数据。实现了真实坐标等比例映射、防重叠自动放大算法、鼠标滚轮缩放与拖拽平移。 |
| 波形图 | Mock | 双 Y 轴 4 序列（电压/频率/有功/无功）24h 曲线（等待后续接入 MATLAB 真实时序数据） |
| 拓扑节点状态信息 | **部分接入 (MySQL)** | 映射了真实节点的电压、功率数据。电流字段暂用随机数占位。点击行联动右侧详情卡。 |
| 场景库视图 | Mock | 6 张场景卡，已优化高清实景配图与暗角遮罩（等待后端场景接口） |
| 仿真任务运行表 | Mock | 任务进度轮询刷新，提交后新任务置顶插入（等待后端任务接口） |
